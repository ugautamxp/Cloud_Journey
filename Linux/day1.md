#### Shell 
It is a Command Line Interface which interpret the commands and tell the OS what to do

### Commands - 
commands are like some executable files
$ **pwd** : Print working Directory - it prints current directory we are in.

$ **ls** : list all the things in the current directory
$ **ls -a** : list all the hidden directory
$ **ls -l** : list all the files in current directory with a lot more details
$ **ls -al**: list all the hidden files in current directory with a lot more  details
$ ls -R : list all the directory and recursive directories and files (folder inside the folder)

$ **mkdir** : make new directory

$ **cd (change directory)** : opens to home directory
$ **cd ..** : go back to previous directory (Path) - .. will also do the same
$ cd .  : current directory (Path) - nothing will change
$ **cd ~** : go to home directory
$ cd ./<directory-name>  : opens <directory-name> directory

$ echo : display string  
$ cat : diplays what is inside the file
$ cat > <File-name> : you can write inside the file(<file-name>) or create the file with th same name (if it is not present)
$ cat <file1> <file2> > <file3> : you can also merge two files
">" : redirect the output - it basically overwrite everything in that file with whatever is before that (if there is nothing you get option to write)

$ man <any-command> : gives a mannual for that particular command.

$ tr : translate ( eg. a-z A-Z : it capitalize everything letter in the the given file and you can also redirect the output with ">")

$ touch : For creating files 

$ xdg-open : open a directory in file manager
$ open : same as above but for mac

$ cp : copy the file

$ mv : move the file, can also rename the file by not providing the directory name but instead providing the name in which you want to rename it

$ rm : remove file
